## ✨ Features

- Editorial design aesthetic — warm ivory palette with burnt sienna accents
- Asymmetric 12-column project grid
- Custom animated cursor with follower ring
- Marquee label strip in the header
- Smooth hover effects and staggered card reveal animations
- Grain noise texture overlay
- Fully responsive — mobile, tablet, desktop
- Zero dependencies — pure HTML & CSS
